# Learn

Twelve modules that go from the basics of deep learning to the open problems at the edge of current research. Each module explains the main ideas, lists readings in order (the first few are the ones to read if you are short of time), gives one exercise, and ends with questions you should be able to answer without notes. A module takes about three to five hours if you read the first group of papers and do the exercise.

| 02 | [Scaling laws](02-scaling.md) | 01 | Survey: Scaling, T1 |

If you have one weekend, do modules 00, 02, 04, 05, 06, 07 and 11 in that order, reading only the first group of papers in each.

The seminal papers behind these modules are listed in one place, each with a line on why it matters, on the [papers](../papers.md) page.

When you finish, the [tracker](../tracker.md) and the [ideas](../ideas.md) page show where things stand and what is still open.
