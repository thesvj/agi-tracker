# Learning path: from foundations to the AGI frontier

Twelve short modules. Each one has the same parts:

- **Goal**: what you will understand at the end.
- **Why it matters for AGI**: the link to the five tests.
- **Core ideas**: the concepts in plain words.
- **Read**: primary sources, in order. ⭐ marks the must-read.
- **Do**: one small hands-on task.
- **Check yourself**: questions you should be able to answer without notes.

**Time:** about 3–5 hours per module if you read the ⭐ items and do the task.
